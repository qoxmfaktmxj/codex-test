# 아치 · 도자기 창 디자인 기록

## 최근 7개 실제 브라우저 비교

2026-11-19부터 11-26까지의 우르, 오와레, 세네트, 로타, 나인 맨즈 모리스, 키르캇, 바그 찰을 Chrome(1440×1000)으로 직접 캡처해 비교했다. 이들은 밝은 종이·점토·청록 계열의 넓은 직사각 게임판, 좌측 제목/설명 또는 수평 레이아웃, 격자와 수평·수직 이동선을 중심으로 한다. 조각은 대체로 둥근 색상 말이며, 물결·리플 같은 가벼운 강조가 사용된다.

## 콘셉트: 아치 · 도자기 창

가나의 3×3 정렬 게임 아치를 **햇빛이 투과하는 원형 도자기 창**으로 만든다. 화면의 주인공은 커다란 원형 방사형 판이며, 9개의 유약 타일이 짧은 대각 연결선으로 묶인다.

- **구도 차별화:** 좌측 안내문+직사각 격자를 쓰지 않고, 중앙의 원형 창 안에 3×3 타일을 떠 있게 배치한다. 상태와 조작은 판 아래의 짧은 띠로 제한한다.
- **타이포 차별화:** 매우 굵고 압축된 영문 소제목과 넓은 자간의 한글 제목을 함께 쓰며, 제목 크기를 보드보다 작게 유지한다.
- **재질·색 차별화:** 청록/산호/종이 대신 석회색 벽, 코발트 유약, 살구색 테라코타 및 반투명 백자 타일을 쓴다. 금색 강조나 어두운 배경은 쓰지 않는다.
- **움직임 차별화:** 선택한 타일은 유약 광택이 천천히 흐르고, 새 말은 짧게 피어나는 도자기 링으로 표시한다. 이동은 안정적인 색/그림자 변화만 사용한다.

## 검증 계획

데스크톱과 375px 모바일에서 실제 Chrome 캡처 및 플레이로 배치→이동→승리→새 판, 마우스/터치와 키보드 포커스, 한글 대비와 가로 스크롤을 확인한다.

## 실제 브라우저 검증 결과

Chrome 1440×1000 및 375×820에서 실제 페이지를 캡처했다. 원형 창과 9개 타일이 각 화면에서 가장 큰 시각 요소로 남았고, 모바일에서 가로 넘침 없이 9개 조작 타일이 유지됐다. 실제 브라우저 클릭으로 푸른 유약 0→1→2 줄을 만들어 승리 문구를 확인했으며, 새 창 버튼으로 초기화할 수 있다. 최근 7개 캡처와 재비교했을 때 원형 중앙 구도, 압축 소제목/한글 제목 조합, 유약 타일 재질, 타일 생성 링 애니메이션이 모두 다른 방향임을 확인했다.
