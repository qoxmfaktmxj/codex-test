# 디자인 비교 · 미니 다마: 보랏빛 극장 좌석표

## 최근 7개 실제 브라우저 비교

2026-09-20부터 2026-09-26까지의 게임을 로컬 HTTP 서버에서 1440px 실제 Chrome 화면으로 캡처해 비교했다. 최근 화면은 청록·코발트·산호 같은 선명한 색의 정원/온실/인쇄소/파도 맥락과 둥근 게임판 프레임, 상단 설명과 하단 조작부가 반복된다. 특히 알케르케는 타일 정원형 교차점 보드, 사목은 온실 격자, 열다섯은 인쇄 활자 판이다.

## 콘셉트

**보랏빛 극장 좌석표**: 무대 조명이 꺼진 뒤 남은 밝은 종이 티켓 위에서 좌석을 옮기는 미니 다마다. 게임판 자체를 공연장 좌석표처럼 크게 두고, 말은 빨강/남색의 납작한 표식으로 표현한다.

## 차별화

1. **구도**: 카드/패널 중심 대신 화면을 거의 채우는 대각선 6×6 좌석표가 주인공이며, 제목은 좌측 가장자리에 세로로 놓는다.
2. **타이포**: 최근의 산세리프 헤드라인 대신 고전 극장 전단 같은 `Georgia` 계열 세리프와 아주 좁은 대문자식 보조 표기를 쓴다.
3. **재질**: 유리·타일·목재 대신 미세한 종이 결, 절취선, 잉크 번짐을 사용한다. 어두운 배경과 금색 강조를 쓰지 않는다.
4. **움직임**: 선택 가능한 좌석은 점멸하는 입장등으로, 말 이동은 짧은 잉크 번짐 착지 효과로 보여 준다.

desktop 1440px와 mobile 390px에서 실제 Chrome 캡처·플레이를 확인한다. 터치/키보드 버튼 조작, 강제 잡기, 승리와 새 공연 시작을 확인하고 최근 7개와 색·재질·구도를 다시 대조한다.
