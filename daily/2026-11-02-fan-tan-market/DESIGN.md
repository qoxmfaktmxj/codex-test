# 시장 풍탄 디자인 기록

## 최근 7개 실제 화면 비교

2026-10-26부터 2026-11-01까지의 중국 장기, 백개먼, 탁구, 페그 솔리테어, 종이 축구, 크리비지, 피그 다이스를 로컬 HTTP 서버의 Chrome 실제 화면으로 캡처해 비교했다. 최근 화면은 축제 뜰·여행 포스터·체육관·관측판·공책·펠트·차통처럼 각각의 소재가 강하지만, 대부분 넓은 배경 위에 중앙 게임 영역과 상단 설명을 둔다.

## 방향

**항구 시장의 청사진 전표**: 밝은 청회색 종이, 진한 남색 잉크, 산호색 인쇄 표식을 사용한다. 게임판은 화면의 거의 모든 시선을 차지하는 두 개의 세로 시장 선반이며, 패널을 반복하지 않는다. 제목은 좁은 전표 머리말처럼 가장자리에 두고, 조작은 판 아래의 짧은 안내선으로 제한한다.

## 차별화

1. **구도**: 중앙 카드 더미 대신 세로 선반 네 개와 교차하는 숫자 눈금을 크게 사용한다.
2. **타이포**: 전표 같은 작은 대문자형 보조 정보와 굵은 한글 명조 제목을 섞어 최근의 포스터/라벨과 다른 문서적 위계를 만든다.
3. **재질**: 펠트·차통·종이 공책 대신 청사진의 백색 인쇄선과 미세한 섬유 결을 사용한다.
4. **움직임**: 둘 수 있는 패는 잉크 번짐처럼 숨쉬고, 놓은 패는 선반에서 짧게 미끄러져 들어간다.

## 검증 계획

데스크톱과 375px 모바일에서 실제 패를 눌러 진행·완료·새 판을 확인하고, Chrome 캡처를 최근 7개 캡처와 다시 비교한다. 키보드 Tab/Enter와 터치 버튼, 명암 대비, 가로 넘침도 확인한다.
