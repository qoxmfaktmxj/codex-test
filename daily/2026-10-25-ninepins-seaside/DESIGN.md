# 나인핀 · 바닷가 산책로 디자인

## 실제 화면 비교

최근 7개(10월 18~24일)를 로컬 HTTP 서버에서 Chrome 실제 화면으로 1440px 캡처해 비교했다. 청사진의 직사각 패 작업대, 온실의 원형 버튼, 활자·지하철·리소그래프의 밝은 인쇄물, 형광 인쇄소의 검은 격자, 횡단보도의 가로 차선 모두 중앙 게임판과 짧은 상단 안내 조합이었다. 최근작은 크림 종이·형광·산호/청록·격자/인쇄 질감이 자주 나타난다.

## 콘셉트

**맑은 파란 타일의 바닷가 나인핀 골목**. 화면은 넓은 수평 레인 하나가 주인공이며, 하단 조작대는 레인 경계에 붙는 얇은 조종 손잡이다. 흰 회벽과 코발트 타일, 토마토색 공으로 지중해 산책로의 선명한 낮빛을 만든다.

## 차별화

1. **구도**: 최근의 정사각/격자 보드가 아닌 매우 넓은 가로 레인과 끝의 핀 삼각형을 사용한다.
2. **타이포**: 응축된 대문자풍 제목과 넓은 자간의 작은 안내를 혼합하고, 게임 정보는 레인 가장자리 표식처럼 배치한다.
3. **재질**: 종이·네온·유리 대신 유광 타일 줄눈, 햇빛 하이라이트, 흰 석고 벽을 쓴다.
4. **움직임**: 공이 레인을 가로지르고 핀이 차례로 쓰러지는 CSS 애니메이션을 사용한다.

어두운 배경/금색 강조/범용 패널을 피하고, 한글 대비와 키보드·터치 조작을 검증한다.
