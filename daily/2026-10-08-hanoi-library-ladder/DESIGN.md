# 하노이 탑 · 도서관 사다리 — 디자인 기록

## 최근 실제 화면 비교

브라우저에서 2026-10-02 마스터마인드, 10-03 아타리고, 10-04 스네이크, 10-05 2048, 10-06 윷놀이, 10-07 달 착륙선을 1440px 캡처로 확인했다. 천공 카드의 가로 행, 점토 격자, CRT 모니터, 인쇄지 타일, 둥근 기와마당, 청록 하늘 활주로가 각각 화면을 지배했다. 10-07 브레이크아웃 폴더에는 실행 파일이 없어 실제 캡처할 수 없었다.

## 콘셉트

밝은 오래된 도서관의 이동식 사다리를 하노이 탑의 세 서가로 재해석한다. 책등이 디스크이며, 작은 책만 큰 책 위에 둘 수 있다.

## 실질적 차별화

1. **구도:** 기존의 가로 패널/격자 대신, 높게 솟는 세 개의 서가와 사다리가 화면 대부분을 차지하는 세로형 게임판.
2. **타이포:** 화면용 글꼴 대신 굵은 명조 계열 제목과 책등의 세로 글자 느낌을 사용한다.
3. **재질:** CRT·점토·종이·타일과 달리 연한 목재 선반, 크림 벽지, 색 바랜 책등을 사용한다.
4. **움직임:** 선택한 책이 옆으로 미끄러지고, 올바른 이동마다 책등이 짧게 정렬되는 전환을 사용한다.

검증: 데스크톱과 375px 모바일에서 실제 이동·종료·새 게임을 플레이하고 캡처한다. 어두운 배경, 금색 강조, 범용 카드 패널은 사용하지 않는다.
