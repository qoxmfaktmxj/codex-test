# 세네트 · 종이 극장 — 디자인 계획

## 실제 비교

2026-11-14부터 2026-11-20까지의 최근 7개 게임을 로컬 HTTP 서버에서 Chrome으로 직접 실행해 1440px 화면 캡처를 비교했다. 최근 화면은 대체로 넓은 상단 제목/상태 영역 아래에 중앙 게임판을 두고, 목재·직물·종이 같은 재질과 둥근 조작 버튼을 사용한다. 오와레와 우르는 보드 주변 장식이 많고, 오목·SOS·헥스·점 잇기는 정방형 또는 격자형 판을 중심으로 한다.

## 방향

세네트는 **밝은 리소그래프 종이 극장**으로 만든다. 커튼이 열린 무대 한가운데에 3×10 보드를 가로로 길게 배치하고, 말은 무대 위 배우처럼 움직인다. 어두운 배경·금색 강조·일반 패널 반복은 쓰지 않는다.

## 최근 게임과의 실질적 차이

1. **구도**: 정방형 판이나 중앙 카드 대신, 좌우 날개와 막대 조명에 둘러싸인 넓고 낮은 가로 무대 보드.
2. **타이포**: 고딕형 UI 대신 굵은 명조 제목과 자간 넓은 소제목을 사용한다.
3. **재질**: 질감 있는 크림 인쇄지, 잉크 번짐 점무늬, 코발트/주홍/연두의 인쇄 잉크만 사용한다.
4. **움직임**: 말 이동은 짧은 좌우 슬라이드, 차례 전환은 조명 점멸로 표현한다.

## 조작과 검증 기준

두 사람이 번갈아 막대를 던진 뒤 같은 색 말을 눌러 이동한다. 같은 칸의 상대 말은 교환하며, 26~29번의 네 안전칸과 정확한 탈출 규칙을 적용한다. 모바일은 가로 스크롤 없이 보드와 말 버튼을 누를 수 있어야 하며, 키보드 Tab/Enter와 재시작, 진행/종료를 확인한다.
