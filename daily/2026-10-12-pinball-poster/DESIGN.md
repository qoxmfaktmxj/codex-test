# 핀볼 · 밤시장 포스터 디자인

## 콘셉트

골목 벽에 붙은 커다란 형광 실크스크린 포스터가 곧 핀볼 테이블이 되는 **거리 인쇄물** 방향이다. 화면의 주인공은 페이지 중앙을 거의 채우는 세로형 핀볼 테이블이며, 조작 설명과 점수는 포스터 가장자리의 작은 활자 블록으로 눌러 놓는다.

## 최근 7개 실제 브라우저 화면 비교

2026-10-06~11의 실제 headless Chrome 캡처를 비교했다. 최근 화면은 원형 마당(윷놀이), 넓은 하늘 장면(착륙선), 얕은 가로형 벽돌판(브레이크아웃), 서가 기둥(하노이), 유리 격자(라이트 아웃), 보자기 격자(리버시), 장부 퍼즐(카쿠로)처럼 게임판 주위에 헤더·상태 블록이 놓이는 구성이 반복된다.

## 차별화 약속

1. **구도:** 일반 가로 패널 대신, 가장자리가 잘린 A2 세로 포스터/핀볼 테이블을 화면 전면에 둔다.
2. **타이포:** 둥근 UI 글꼴 대신 압축된 굵은 한글 제목과 거친 자간의 인쇄소 레이블을 쓴다.
3. **재질:** 유리·보자기·종이 장부 대신 형광 잉크, 거친 벽지, 검은 실크스크린 망점 질감을 쓴다.
4. **움직임:** 공의 탄성 이동, 범퍼의 짧은 잉크 번짐, 플리퍼의 회전 반동을 사용한다.

어두운 배경+금색 강조와 범용 카드 패널은 사용하지 않는다. 색은 살구색 벽지, 청록 잉크, 산호색과 산성 라임으로 정한다. 데스크톱과 모바일에서 실제 조작·캡처 후 판독성, 터치, 키보드, 시작·종료·재시작을 확인한다.
