# 천점 주사위 · 세탁표 교환소 디자인

## 실제 비교

2026-11-11부터 2026-11-17까지의 7개 게임을 로컬 HTTP 서버와 Chrome 실제 캡처로 비교했다. 최근 화면은 형광 표지 다트, 민트 오락 레인, 하늘빛 마당, 항공우편 종이, 수조형 육각 타일, 기상 전보, 한지 격자처럼 넓은 게임판과 테마성 재질을 중심에 둔다.

## 방향

밝은 회백색 세탁 영수증 위에 대담한 청색 번호·주홍 도장을 찍는 **공업용 인쇄물** 방향이다. 여섯 주사위가 커다란 계량 트레이를 채우며 게임판 자체가 점수 선택기가 된다.

## 차별화

1. **구도**: 상단 제목 아래에 단일 가로 주사위 트레이를 크게 두고, 점수표는 가장자리의 좁은 전표 띠로 물린다.
2. **타이포**: 굵은 압축 숫자와 영수증 같은 모노스페이스 보조문을 조합한다.
3. **재질**: 종이·나무·금색 대신 회백색 열전사 전표, 파란 인쇄 잉크, 주홍 고무 도장 질감을 쓴다.
4. **움직임**: 굴릴 때 주사위가 짧게 흔들리고, 고른 주사위는 도장처럼 내려앉는다.

데스크톱/모바일에서 실제 플레이, 한글 대비, 터치·키보드 조작, 종료와 새 판을 확인한다.
