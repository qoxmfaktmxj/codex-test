# 디자인 계획 — 마스터마인드 · 천공 카드실

## 실제 화면 비교

2026-10-02에 최근 7개 게임(사목, 알케르케, 미니 다마, 칼라하, 보글, 펜테, 지뢰찾기)을 `python3 -m http.server`와 headless Chrome(1440×1000)으로 실제 실행·캡처하여 비교했다. 최근 화면은 각기 온실 격자, 타일 교차점, 극장 좌석, 조수 웅덩이, 활자 서랍, 네온 코트, 기상 지도처럼 넓은 장면형 게임판을 중심에 두되, 조작 안내와 제목이 상단에 놓이는 구성이 반복된다.

## 방향

**1950년대 데이터 처리실의 천공 카드**: 암청색/금색 또는 일반적인 카드 패널을 쓰지 않고, 따뜻한 재생지 바탕 위에 먹색 잉크·주홍·청록·황토의 잉크 점을 쓴다. 게임판은 카드 한 장 전체가 되며, 열 줄의 구멍 행과 오른쪽의 검산 핀이 직접 보이는 구조다.

최근 7개와의 실질적 차별:

1. **구도**: 제목 영역보다 훨씬 큰 세로 천공 카드가 화면 중앙을 차지하고, 색 선택기는 카드 아래의 물결형 잉크 띠로 배치한다.
2. **타이포**: 현대 산세리프 대신 `Georgia` 계열의 활자 제목과 촘촘한 대문자풍 고정폭 정보 글자를 결합한다.
3. **재질**: 발광·유리·타일 대신 섬유 종이, 인쇄 오차선, 실제 구멍처럼 보이는 원형 절취 그림자를 사용한다.
4. **움직임**: 추측을 제출할 때 새 행이 인쇄되는 짧은 잉크 타이프 애니메이션과 선택 점의 안정적인 점등을 사용한다.

접근성: 모든 색은 번호/한글 이름과 함께 읽히며, 버튼에 라벨과 키보드 조작을 제공한다. 375px에서는 카드 폭을 유지하면서 색 선택기를 3×2로 접고 가로 넘침을 막는다.
