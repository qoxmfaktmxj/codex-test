# 오목 · 먹빛 정원 디자인

## 실제 비교

2026-11-10부터 2026-11-16까지의 7개 게임을 로컬 HTTP 서버에서 Chrome headless로 실제 캡처해 비교했다. 최근 화면은 각각 빙상 경기장, 형광 표지판, 세로 오락 레인, 고무 코트, 항공우편, 수조형 육각 타일, 기상 전보라는 강한 테마의 넓은 게임판과 제목/상태 영역 조합이다. 새 화면은 이 레이아웃과 색·재질을 반복하지 않는다.

## 방향

밝은 한지 위에 먹과 주홍 낙관만 쓰는 **동양 목판화** 오목이다. 화면 중심은 나무 틀 대신 넓게 비운 정사각 한지 게임판이며, 정보는 좌우가 아닌 상단의 작은 인장 띠로 압축한다.

## 차별화

1. **구도**: 상단 상태 띠와 커다란 단일 한지 격자를 사용하고, 최근의 카드/경기장/세로 레인 구도를 피한다.
2. **타이포**: 명조 계열의 편집형 한글 제목과 작은 낙관 레이블을 사용한다.
3. **재질**: 어두운 배경·금색 대신 종이 섬유, 번진 먹돌, 붉은 인주 질감을 사용한다.
4. **움직임**: 마지막 수가 먹 번짐처럼 짧게 퍼지고, 승리 다섯 알은 순서대로 맥동한다.

데스크톱과 모바일 실제 플레이/캡처에서 한글 대비, 터치·키보드 조작, 진행·종료·새 판을 검증한다.
