# 숫자 닫기 · 자개 부채판

## 실제 화면 비교

2026-11-04에 최근 7개 게임(탁구 체육관, 페그 솔리테어 관측소, 종이 축구 점수판, 크리비지 천 테이블, 피그 다이스 차통, 풍탄 항구 전표, 기억 퀼트)을 로컬 HTTP 서버와 headless Chrome으로 각각 캡처해 비교했다. 최근 화면은 밝은 인쇄물·천·운동장 질감, 직사각형 게임판, 상단 제목과 보조 패널의 구성이 많았다.

## 콘셉트

고전 **숫자 닫기(Shut the Box)**를 ‘바다빛 자개로 만든 부채형 여행 놀이판’으로 해석한다. 주사위 목표와 합이 같은 숫자 조각을 골라 모두 닫는 1인 게임이다. 게임판이 화면의 중심을 차지하고, 숫자 조각은 부채살처럼 방사형으로 배열한다.

## 차별화 약속

1. **구도:** 직사각형 격자·패널 대신 반원형 부채살의 대형 방사형 보드를 사용한다.
2. **타이포:** 좁고 굵은 안내 문구와 크게 회전한 숫자 조각을 조합해 표지판 같은 리듬을 만든다.
3. **재질:** 종이·천 대신 옅은 민트, 산호, 진주색의 자개 광택과 짙은 남청 외곽을 사용한다. 어두운 배경+금색 강조는 쓰지 않는다.
4. **움직임:** 숫자 조각은 선택 시 들리고, 닫을 때 부채 중심으로 접히며, 주사위 결과는 짧게 흔들린다.

## 검증 계획

desktop 1280×900 및 mobile 390×844에서 실제 플레이, 주사위 굴리기, 숫자 선택/취소, 합계 제출, 종료와 새 게임을 검증하고 스크린샷을 저장한다. 최근 게임과 시각적으로 겹치면 위 네 요소를 유지하도록 수정 후 재캡처한다.
