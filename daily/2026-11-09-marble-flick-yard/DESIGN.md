# 구슬치기 · 분필 마당 디자인 기록

## 실제 화면 비교

2026-11-09 KST에 최근 7개 게임(풍탄 항구 전표, 페어 기억 놀이 다락방 퀼트, 숫자 닫기 자개 부채판, 코나네 흙빛 작업대, 파치시 강변 두루마리, 세트 태양 인쇄소, 키노 역광 벽보국)을 로컬 HTTP 서버에서 Chrome 실제 데스크톱 화면으로 캡처해 비교했다. 최근 화면은 종이·직물·점토·벽보 같은 평면 재질과 사각/격자/카드 단위, 따뜻한 크림 또는 진한 남색 배경이 많았다.

## 선택한 방향

밝은 라일락 석회 마당에 커다란 원형 분필 고리를 기울여 놓은 **분필 놀이터**다. 게임판을 화면의 가장 큰 요소로 두고, 구슬은 클릭 뒤 짧게 굴러가며 점수 고리에 안착한다.

최근 7개 대비 차별화:

1. **구도:** 카드·직사각 격자 대신 화면을 가로지르는 큰 원형 과녁과 비대칭 점수 꼬리표.
2. **타이포:** 단정한 산세리프 대신 높은 대비의 명조 계열 제목과 넓은 자간의 작은 안내문.
3. **재질:** 종이/직물/점토 대신 분필 가루, 거친 석회 바닥, 유리 구슬 광택.
4. **움직임:** 선택한 구슬이 고리 안으로 굴러가고 점수 숫자가 짧게 떠오르는 움직임.

검증 계획: 데스크톱(1440px)과 모바일(390px)에서 클릭/키보드 조작, 점수 진행·승리·새 판을 실제 Chrome으로 확인하고 캡처한다.
