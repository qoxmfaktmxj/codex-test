# 키노 · 역광 벽보국 디자인

## 최근 7개 실제 화면 비교

2026-11-01부터 2026-11-07까지의 게임을 로컬 HTTP 서버에서 Chrome headless로 1440px 화면 캡처해 직접 비교했다. 최근 화면은 밝은 종이·천·작업대 질감 위에, 중앙의 사각형 또는 방사형 보드와 상단 설명/수평 조작줄을 둔 구성이 많았다. 특히 퀼트·세트는 반복 타일, 숫자 닫기는 부채꼴, 파치시는 기울어진 수로를 사용한다.

## 방향

거리의 야간 추첨 벽보를 연상시키는 **강렬한 2색 실크스크린 포스터**로 만든다. 크림 종이와 주황 잉크를 배경으로 하고, 큰 남색 5×5 숫자판이 화면 대부분을 차지한다. 게임판이 장식이 아니라 바로 티켓 겸 추첨판이다.

## 최근 화면과의 실질적 차이

1. **구도**: 상단 헤더 + 별도 패널 대신, 보드 주변으로 텍스트와 조작을 붙인 세로형 벽보 구도.
2. **타이포**: 두꺼운 한글 전단 제목과 좁은 수직 라벨을 대조해 신문/공방 톤을 피한다.
3. **재질**: 종이 질감/카드 그림자 대신 평면 실크스크린 잉크의 거친 점망 패턴과 오프셋 테두리.
4. **움직임**: 선택 칸은 안쪽으로 눌리며 원형 잉크 링이 퍼지고, 추첨 결과는 각 칸이 짧게 번쩍인다.

## 검증 계획

375px와 1440px에서 게임판, 선택·추첨·다시 고르기, 버튼 및 키보드 Enter 동작을 Chrome으로 확인한다. 실제 캡처를 저장하고 최근 7개 캡처와 재비교한다.
