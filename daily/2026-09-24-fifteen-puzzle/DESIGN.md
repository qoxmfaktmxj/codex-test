# 열다섯 · 활자 정렬실 디자인 기록

## 최근 7개 실제 브라우저 화면 비교

2026-09-12 밍망은 진한 종이 질감과 원형 돌, 09-13 바가텔은 세로형 목재 오락기, 09-14 셔플보드는 넓은 가로 코트, 09-20 여우와 거위는 포스터식 선과 산호색, 09-21 오델로는 크림 종이 위 제도선, 09-22 님은 성냥 공방의 하늘색 벽, 09-23 삼목은 청록 파도와 비스듬한 표지판을 실제 Chrome 화면 캡처로 비교했다. 최근작에는 재질을 드러낸 장면형 배경, 설명이 위/아래에 붙는 구도, 원형 말 또는 선형 보드가 많다.

## 방향

**활자 정렬실**: 밝은 회백색 인쇄 용지 위에 코발트 잉크와 주홍 교정 표시만 쓰는, 1920년대 조판 견본지 같은 열다섯 퍼즐이다. 게임판이 화면 왼쪽의 가장 큰 물체이며, 번호 활자가 조판 블록처럼 맞물린다.

## 실질적 차별화

1. **구도**: 중앙 장면/카드 대신 큰 4×4 정사각 판을 왼쪽으로 밀고, 제목·조작을 오른쪽의 세로 조판선에 배치한다.
2. **타이포**: 산세리프 게임 헤드라인 대신 고대비 세리프와 세로 회전된 작은 조판 라벨을 사용한다.
3. **재질**: 목재·바다·어두운 판 대신 거친 인쇄지, 잉크 번짐 가장자리, 에나멜 활자 블록의 평면 대비를 사용한다.
4. **움직임**: 말 놓기/물리 발사 대신 이동 가능한 활자 블록의 180ms 잉크색 전환과 완료 시 잉크 맥동을 사용한다.

## 검증 계획

Chrome에서 데스크톱 1440px, 모바일 390px로 실제 플레이(인접 타일 클릭, 키보드 방향키, 완료, 초기화)를 확인하고 두 화면을 저장한다. 한글 문구, 명암, 터치 크기, 수평 스크롤을 함께 확인한다.
