# 함대 사냥 · 청사진 조선소 — 디자인 기록

## 실제 비교

2026-10-18에 최근 7개 게임(핀볼 포스터, 빙고 전광판, 필로스 온실, 나인 맨즈 모리스, 수라카르타 해도, 미니 스도쿠, 소코반)을 로컬 HTTP 서버에서 Chrome headless로 각각 1280×900 캡처하여 비교했다. 최근 화면은 대체로 중앙의 정방형 보드와 상단 제목/보조 정보, 종이·벽돌·포스터 질감, 따뜻한 크림 또는 어두운 색면을 사용한다.

## 방향

* **구도:** 화면 전체를 가로로 가르는 조선소 도면으로 만들고, 대형 2×6 마작 패 작업대를 비대칭 좌측에 둔다. 우측에는 얇은 작업 현황만 배치해 게임판이 주인공이 된다.
* **타이포:** 제목은 굵고 압축된 `Impact` 계열, 좌표와 상태는 넓은 자간의 모노스페이스로 분리한다. 최근의 부드러운 제목/본문 조합을 반복하지 않는다.
* **재질·색:** 종이·나무·야간 네온 대신 밝은 청색 도면 바탕, 백색 선, 주황 안전표식과 잉크 번짐을 사용한다. 금색/어두운 배경/일반 패널 조합은 피한다.
* **움직임:** 선택 패는 주황 안전표식으로 즉시 전환되고, 짝이 맞으면 작업대에서 사라진다. 버튼 확대는 사용하지 않는다.

## 접근성 및 검증 계획

각 칸은 키보드 초점과 한글 `aria-label`을 갖는다. 데스크톱과 375px 모바일에서 실제로 공격·승패·초기화를 확인하고 캡처한다. 명암 대비가 높은 흰 선/짙은 청색/주황 표식으로 읽기 쉬움을 유지한다.
