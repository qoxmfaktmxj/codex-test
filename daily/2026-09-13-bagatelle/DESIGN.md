## 콘셉트: 햇빛 드는 오래된 유원지의 목재 오락기

주인공은 세로로 긴 실물형 바가텔. 밝은 미색 인쇄물 배경에 먹색/주홍 잉크, 호두나무 테두리, 밝은 자작나무 게임면, 은빛 못과 쇠구슬. 금색 테마는 사용하지 않는다.

1. **구도**: 대형 게임판 자체가 오브젝트. 좌측 비대칭 명조 제목/규칙 종이, 점수 계수기와 조작부는 오락기 상하에 부착. 모바일은 작은 인쇄물 머리글 뒤 게임판을 바로 배치.
2. **타이포**: 한글 명조(설치된 Noto Serif CJK KR/Batang 계열), 숫자는 Georgia로 활판/기계식 계수기를 연상. 기존 고딕 대제목 복제 금지. 외부 폰트 다운로드 없음.
3. **재질**: CSS 나뭇결, 맞물린 프레임, 나사, SVG 조각 선과 반사광. 배경/패널 전면 그라디언트 대신 물체 표면의 깊이에 한해 사용.
4. **움직임**: 우측 스프링 발사대→위쪽 경사 가이드→못 충돌→하단 점수 홈. 고정 시간 간격 물리; 도착 순간에만 득점. reduced-motion에서는 장식 효과와 잔상 제거, 게임 물리는 유지.

디자인 스킬 검색의 활자 중심 빈티지 제안만 채택. 일반적인 파랑/주황 블록 쇼케이스와 hero/features/CTA 구성은 이 게임의 맥락과 달라 채택하지 않음.

## 기능/검증 계획

한 판 다섯 공, 세기 조절, 마우스·터치·키보드 발사, 진행 중 중복 발사 차단, 새 게임은 즉시 진행 취소. 중력/탄성/마찰/못/경사벽/하단 칸막이의 실제 충돌. NaN/잘못된 입력 방어, 점수 중복 방지, 다양한 세기의 유한 시간 종료를 테스트 먼저 작성한다. 별도 리뷰, 전체 테스트, 375/768/1024/1440 화면과 모바일 실제 터치 플레이로 검증한다.

## 구현 후 시각 리뷰

- 1440px: 왼쪽 활판형 제목과 사용표, 오른쪽 독립된 목재 기계로 구성. 넓은 설명 패널 대신 물체로서의 게임판이 주인공이다. 기존 밝은 두 게임의 중앙 카드와도 다르다.
- 768px: 제목/사용표와 세로 오락기의 두 열이 충돌하지 않는다. 게임판 내부 칸막이/못/발사 레일은 동일한 물리 좌표에서 그린다.
- 375/390px: 압축된 명조 머리글 아래 게임판이 바로 등장. 조작부가 판에 붙고 사용표는 아래로 이동한다. 수평 스크롤 없음. 실제 터치 다섯 공 완료.
- 주홍/먹색 인쇄, 은빛 핀, 세로 나뭇결과 밝은 종이 조합. 기존 어두운 화면/금색 버튼/고딕 대제목/중앙 사각 패널 재사용 없음.
- 공의 우측 발사→상단 경사벽 반사→못 충돌→홈 도착을 실제 캡처했다. 장식 원/마름모는 득점 버튼이 아니다.
- 대비 계산: 본문 11.33:1, 주홍 상태 6.16:1, 보조 설명 6.10:1, 점수 홈 5.36:1, 발사 글자 4.57:1, 판면 인쇄 5.18:1. 주요 작은 글자도 4.5:1 이상.
- `screenshot.png`, `screenshot-mobile.png`, `evidence/viewport-*.png`, `evidence/*in-flight.png`, `evidence/mobile-finished.png`를 실제 이미지로 열어 검토했다.
