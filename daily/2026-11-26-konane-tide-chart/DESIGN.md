# 바그 찰 · 조류 해도 디자인

## 실제 비교

최근 7개(11/18–11/24)를 로컬 HTTP 서버에서 Chrome으로 직접 캡처해 비교했다. 공통적으로 제목이 상단에 있고, 중앙 게임판과 하단 상태/재시작 제어가 있는 단일 화면 구성이었다. 모래 탁자는 따뜻한 토질, 유리 회랑은 반투명 성당색, 역 시계는 원형 시계, 종이 극장은 긴 가로 보드, 베틀은 짙은 직물, 점토 경주는 토기색, 세탁표는 회백색 전표 재질을 사용한다.

## 방향

네팔의 고전 추격 게임 바그 찰을 **밝은 조류 해도**로 표현한다. 최근의 어두운 배경·금색 강조·일반 패널을 쓰지 않고, 넓은 청록 종이 바탕 위에서 5×5 자갈 격자가 화면의 주인공이 된다.

## 실질적 차별점

1. **구도**: 긴 세로의 헤드라인을 보드 왼쪽 가장자리에 붙이고, 보드는 오른쪽으로 기울어진 해도 좌표선 위에 크게 배치한다. 좁은 화면에서는 제목을 보드 위로 접되 보드가 화면 폭을 최대한 점유한다.
2. **타이포**: 균일한 앱 제목 대신 굵은 콘덴스드 산세리프와 작은 좌표 숫자를 대조해 항해 차트처럼 보이게 한다.
3. **재질**: 모래·점토·유리·직물 대신 청록색 잉크, 흰 포말, 짙은 현무암 자갈의 평면 인쇄 질감과 얇은 등압선으로 구성한다.
4. **움직임**: 선택 자갈의 잔물결과 착지점의 파문이 짧게 퍼지며, 점프한 자갈은 떠오르지 않고 옆으로 미끄러져 사라진다.

## 조작/접근성

자갈을 누른 뒤 파문이 있는 착지점을 누른다. 필수 점프를 안내하고, 새 항해 버튼과 키보드 포커스가 제공된다. 대비가 높은 남청 텍스트와 흰/검정 자갈을 사용한다.
