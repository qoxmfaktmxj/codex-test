# 나인 맨즈 모리스 · 유리 회랑 — 디자인 기록

## 최근 7개 실제 브라우저 화면 비교

2026-11-23에 Chrome headless로 SOS, 오목, 천점 주사위, 우르, 오와레, 세네트, 로타를 각각 1440px 화면으로 캡처해 비교했다. 모두 밝은 배경의 물성 테마와 중앙 게임판을 사용하지만, 각각 가로형 보드·원형 시계·격자·주사위/구멍판처럼 서로 다른 지오메트리를 갖는다. 이번 화면은 이들과 겹치지 않도록 **세로로 긴 성당 창**, 가는 납선의 정사각 고리, 아래에서 위로 흐르는 색유리 빛을 주인공으로 삼는다.

## 방향

- **구도:** 설명과 조작을 창의 좌우 여백에 얇게 배치하고, 화면 높이 대부분을 차지하는 세로 보드를 우선한다.
- **타이포:** 둥근 UI 글꼴 대신 고전적인 명조 계열의 한글 제목과 작은 대문자풍 안내문을 조합한다.
- **재질:** 종이·점토·직물 대신 반투명 청록/산호 색유리, 납선, 흰 석회 벽의 대비를 사용한다.
- **움직임:** 선택한 말에는 미세한 유리 광채가 맥동하고, 승리 시 창의 빛줄기가 퍼진다. 200ms 전환을 지키며 동작 감소 설정도 존중한다.

검증 목표는 375px와 1440px에서 가로 스크롤 없이 말 배치·이동·제거·승리·다시 시작을 실제 조작으로 확인하고 캡처하는 것이다.
