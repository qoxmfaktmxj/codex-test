# 페어 기억 놀이 · 다락방 퀼트

## 실제 브라우저 비교

2026-11-03에 로컬 HTTP 서버와 Chrome headless로 최근 7개(미니 백개먼, 미니 탁구, 페그 솔리테어, 종이 축구, 크리비지, 피그 다이스, 시장 풍탄)를 1440px 화면에서 각각 실행·캡처해 비교했다. 최근 화면은 항로/코트/원형 관측판/공책 격자/펠트/차통/전표처럼 넓은 가로 장면과 강한 물성 테마가 중심이다.

## 방향

밝은 다락방의 손바느질 퀼트를 한 장의 정사각형 놀이판으로 크게 배치한다. 일반 패널이나 어두운 배경·금색 강조를 쓰지 않는다. 차별점은 다음 네 가지다.

1. **구도**: 제목과 조작을 좌우 장식으로 밀어내고, 4×4 퀼트 판을 화면의 주인공으로 둔다.
2. **타이포**: 책 표지 같은 굵은 세리프 제목과 작은 바느질 라벨을 조합한다.
3. **재질**: 종이/펠트가 아닌 밝은 면직물 조각, 스티치, 실밥 그림자를 사용한다.
4. **움직임**: 조각은 뒤집힐 때만 짧게 회전하고, 맞춘 조각은 재배치 없이 실밥처럼 잔잔히 빛난다.

모바일에서는 퀼트가 너비 전체를 차지하며 조작 버튼은 판 아래로 이동한다. 키보드 Tab/Enter 및 터치로 조각을 뒤집고, 완료 뒤 새 이불 버튼으로 다시 시작한다.
