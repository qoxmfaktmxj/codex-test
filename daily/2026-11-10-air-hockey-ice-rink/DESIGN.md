# 에어 하키 · 빙판 라디오룸 디자인 기록

## 실제 화면 비교

2026-11-10 KST에 최근 7개 게임(페어 기억 놀이 다락방 퀼트, 숫자 닫기 자개 부채판, 코나네 흙빛 작업대, 파치시 강변 두루마리, 세트 태양 인쇄소, 키노 역광 벽보국, 구슬치기 분필 마당)을 로컬 HTTP 서버에서 Chrome 실제 데스크톱 화면으로 다시 캡처해 비교했다. 최근 화면은 인쇄물·직물·점토·종이 같은 정적인 재질, 사각/원형 보드, 따뜻한 크림 또는 남색의 편집형 화면이 주류였다.

## 선택한 방향

밝은 얼음과 청록 라인을 쓴 **빙판 라디오룸**의 에어 하키다. 라디오 중계의 스코어보드는 가장자리로 밀어내고, 퍽·패들·골대가 있는 세로형 아이스 링크가 화면을 지배한다. 클릭/드래그 또는 방향키로 내 패들을 움직여 5점을 먼저 낸다.

최근 7개 대비 차별화:

1. **구도:** 카드·과녁·격자 대신 세로로 긴 전면 아이스 링크와 양 끝 골대를 주인공으로 둔다.
2. **타이포:** 명조/편집형 제목 대신 굵고 압축된 스포츠 중계체와 숫자 중심 전광판을 사용한다.
3. **재질:** 종이·직물·점토·분필 대신 반투명 아크릴, 서리 낀 얼음, 네온 테이프 라인을 사용한다.
4. **움직임:** 퍽이 반사되며 잔상과 골 섬광을 남기고, 패들은 포인터·키보드를 즉시 따라간다.

검증 계획: 데스크톱(1440px)·모바일(390px) Chrome에서 포인터/터치와 방향키, 득점·종료·새 경기, 가로 넘침 여부를 확인하고 실제 캡처를 저장한다.
