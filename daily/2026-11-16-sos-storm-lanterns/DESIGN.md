# SOS · 폭풍 등대국 디자인 기록

## 최근 7개 실제 브라우저 비교

2026-11-09부터 2026-11-15까지의 게임을 `python3 -m http.server`와 Chrome 헤드리스로 각각 실행해 캡처했고, 이 폴더의 `recent-comparison/`에서 비교했다. 최근 화면은 원형 고리·다트판·세로 레인·육각 타일처럼 강한 단일 보드와, 청록·산호·크림 계열의 오락기/인쇄물 재질이 두드러졌다. 특히 점 잇기와 헥스는 규칙적인 보드 옆에 일반적인 상단 제목과 하단 조작부를 둔다.

## 새 방향

**폭풍 등대국**은 해가 비친 회색-하늘색 기상 전보 용지 위에서 SOS를 찾는 5×5 문자 신호판이다. S와 O를 번갈아 놓아 가로·세로·대각선 SOS를 만들면 즉시 한 번 더 둔다. SOS를 만들지 못하면 교대하고, 판이 찰 때 더 많은 신호를 만든 쪽이 이긴다.

최근작과의 실질적 차별점:

1. **구도**: 넓은 하늘색 여백의 중앙에 세로형 문자 신호판을 매달고, 상태는 보드 위의 얇은 기상 띠로 겹친다. 카드/하단 패널 구조를 쓰지 않는다.
2. **타이포**: 제목은 좁고 굵은 서체, 게임 문자는 선박 신호기를 닮은 대형 세리프 문자로 조합한다. 최근의 둥근 타일/일반 산세리프와 다르다.
3. **재질·색**: 어두운 배경과 금색을 피하고, 흰 전보지·잉크 남색·주황 경보등·빗방울 반투명막을 사용한다.
4. **움직임**: 막 만든 SOS의 세 칸이 짧게 점멸하고, 차례 띠의 점선이 바람처럼 흘러간다. 버튼 확대 효과는 사용하지 않는다.

게임판이 화면의 주인공이며, 데스크톱과 모바일에서 같은 5×5 판을 유지한다. 키보드 Tab/Enter와 터치 조작을 모두 제공한다.
