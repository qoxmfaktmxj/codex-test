# 로타 · 역 시계

## 실제 최근 7개 화면 비교

2026-11-15부터 2026-11-21까지의 7개 게임을 로컬 HTTP 서버에서 Chrome으로 각각 실행하고 1440px 화면을 캡처해 비교했다. 육각 수조, 전보 격자, 한지 바둑판, 세탁 전표, 점토 경주로, 직물 베틀, 종이 극장은 모두 넓은 가로형 장면 안에 게임판을 넣는 구성이고, 질감 있는 평면 재료와 하단 제어 영역을 공통으로 쓴다. 새 화면은 이 반복을 피한다.

## 콘셉트

고대 로타를 `역 시계`라는 밝은 기차역 기계식 시계의 정면으로 해석한다. 두 사람이 세 말씩 놓고, 배치가 끝난 뒤 인접한 빈 칸으로 움직여 가로·세로·대각선 한 줄을 먼저 만든다.

### 의도적 차별점

1. **구도**: 페이지 중앙의 큰 원형 시계판이 거의 화면 전체를 차지하는 세로형 포스터 구도다. 정보는 시계의 상단 눈금과 하단 전광판에 흡수해 별도 패널을 만들지 않는다.
2. **타이포**: 좁고 굵은 역 안내판 계열의 대문자성 한글 제목과 숫자 눈금을 사용하고, 설명은 작은 표지판 문장으로 제한한다. 최근 게임의 서정적 이탤릭 제목과 다르게 간결하고 기계적이다.
3. **재질**: 어두운 배경·금색 강조 대신, 밝은 석회 벽과 코발트 법랑 시계판, 적색/크림 자석 말을 사용한다. 얇은 금속 테두리와 유리 반사가 시계 재질을 만든다.
4. **움직임**: 현재 차례의 시계 바늘이 회전하고, 선택 가능한 칸은 짧은 점멸 링으로 안내하며, 말을 놓거나 이동하면 중심으로 잔잔한 동심원이 퍼진다. `prefers-reduced-motion`에서는 정지한다.

## 검증 기준

- desktop(1440px)과 mobile(390px)에서 원형 3×3 게임판이 화면의 주인공이며 가로 스크롤이 없어야 한다.
- 한글 문구, 키보드 Tab/Enter 조작, 터치/클릭, 진행·승리·리셋을 확인한다.
- 최근 7개 캡처와 재비교해 원형 시계·밝은 법랑·수직 포스터·회전 바늘이 최근 화면과 혼동되지 않는지 확인한다.
