# 다트 · 길찾기 표지판 디자인 기록

## 실제 화면 비교

2026-11-11 KST에 최근 7개 게임(숫자 닫기 자개 부채판, 코나네 흙빛 작업대, 파치시 강변 두루마리, 세트 태양 인쇄소, 키노 역광 벽보국, 구슬치기 분필 마당, 에어 하키 빙판 라디오룸)을 로컬 HTTP 서버에서 Chrome 실제 데스크톱·모바일 화면으로 캡처해 비교했다. 최근 화면은 크림/파스텔 기반의 공예 재질, 넓은 보드와 보조 설명의 조합, 원형 또는 사각 게임판을 중심으로 한 차분한 편집 구성이 많았다.

## 선택한 방향

형광 연두·코발트·주홍의 **도시 길찾기 표지판**을 겹쳐 만든 301 다트판이다. 화면 가장자리는 도로 표지와 점수 화살표만 남기고, 페인트 칠한 큰 다트 원판을 주인공으로 둔다. 원판을 직접 클릭하거나 숫자 키 1~9·0으로 조준해 0점에 먼저 도달하면 이긴다.

최근 7개 대비 차별화:

1. **구도:** 카드형 보조 패널 대신, 화면을 가득 쓰는 커다란 원형 다트판과 가장자리의 비대칭 방향 표지를 쓴다.
2. **타이포:** 명조·편집 제목 대신 좁고 굵은 교통 표지판식 대문자 숫자와 수직 화살표 레이블을 쓴다.
3. **재질:** 종이·직물·점토·빙판 대신 반사 테이프, 거친 도장 금속, 무광 도로 페인트의 겹친 고리를 쓴다.
4. **움직임:** 던질 때 다트가 중심을 향해 짧게 꽂히고, 점수 화살표가 이동하며 남은 점수가 깜빡인다.

검증 계획: 데스크톱(1440px)·모바일(390px) Chrome에서 원판 클릭, 키보드, 버스트·승리·새 게임, 가로 넘침과 한글 대비를 실제 플레이 및 캡처로 확인한다.
