# 점 잇기 · 파도 우체국 디자인

## 실제 비교

2026-11-07부터 2026-11-13까지의 7개 게임을 로컬 HTTP 서버에서 Chrome 실제 화면으로 데스크톱(1440×1000)·모바일(390×844) 캡처해 비교했다. 최근 화면은 원형 표적(다트·구슬치기), 세로 레인(스키볼), 큰 카드/번호 격자(세트·키노), 차가운 경기장(에어 하키), 마당 위 작은 오브젝트(공기놀이)가 중심이었다. 각각의 캡처는 `.visual-review/`에서 직접 비교했다.

## 콘셉트

**파도 우체국의 항공우편 점 잇기**. 사람이 가장자리 선을 눌러 작은 우표 칸을 완성하고, 자동 응답하는 우체국 상대와 더 많은 칸을 차지한다. 화면의 주인공은 가로로 넓은 4×4 우표 판이며, 제목·점수는 판 밖의 작은 우편 소인처럼 물러난다.

## 최근 게임과의 차별점

1. **구도**: 가운데 원형/세로 레인/카드 모음 대신, 파도처럼 기울어진 테두리를 가진 넓은 점-선 격자를 최대 면적으로 둔다.
2. **타이포**: 굵은 현대 산세리프 헤드라인 대신 `Batang` 계열의 인쇄물 제목과 좁은 모노 우편 소인 숫자를 조합한다.
3. **재질·색**: 어두운 바탕·금색 강조와 일반 패널을 쓰지 않고, 바랜 항공우편 종이·코발트 잉크·산호 우표·민트 봉인색을 사용한다.
4. **움직임**: 선을 그을 때 잉크가 번져 나가고, 칸을 얻을 때 우표가 살짝 찍히는 CSS 애니메이션을 쓴다. 최근의 구슬/퍽 물리 움직임을 반복하지 않는다.

## 검증 계획

데스크톱과 390px 모바일에서 실제 클릭·키보드(탭/엔터)로 선 그리기, 칸 완성, 상대 턴, 종료 및 새 게임을 확인한다. Chrome 실제 캡처를 `screenshot.png`, `screenshot-mobile.png`에 저장하고 최근 캡처와 재비교한다.
