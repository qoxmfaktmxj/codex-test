# 점과 상자 · 리소그래프 작업대 — 디자인 기록

## 실제 비교

2026-10-22에 최근 7개(수라카르타 항구 해도, 미니 스도쿠 종이접기, 소코반 성냥갑 창고, 마작 패 맞추기 청사진 조선소, 차임 기억놀이 유리 온실, 주사위 다섯 활자 공방, 쿼리도 지하철 노선도)를 로컬 HTTP 서버에서 Chrome headless로 각각 실행해 1440×1000 화면을 캡처하고 비교했다. 최근작은 밝은 인쇄물·도면·온실·공방 등 질감 있는 무대와 직사각 게임판, 상단 제목 및 주변 설명이 반복된다.

## 콘셉트

점과 상자를 네온/금색이나 카드 대시보드가 아닌 **청록·자홍의 2색 리소그래프 포스터**로 해석한다. 페이지 전체는 거친 크림 종이, 중앙의 거의 정사각형 대형 점판은 번진 잉크 점과 오프셋 어긋남을 가진다. 상자를 닫으면 해당 색 잉크가 판 위에서 인쇄되듯 스며든다.

## 차별화

1. **구도:** 위계적인 헤더/패널 대신, 화면 대부분을 차지하는 정사각 점판과 가장자리의 세로 점수 인쇄로 구성한다.
2. **타이포:** 범용 산세리프 대신 넓고 무거운 제목과 좁은 캡션을 혼용한 포스터 조판을 사용한다.
3. **재질:** 종이 섬유·하프톤·잉크 어긋남을 CSS 패턴으로 표현한다. 어두운 배경/금색 강조를 쓰지 않는다.
4. **움직임:** 선은 잉크가 스며드는 듯 그려지고, 완성 상자는 짧은 인쇄 펄스로 채워진다.

## 검증 계획

데스크톱(1440px)과 모바일(390px)에서 실제 Chrome으로 클릭, 키보드 진행, 종료, 새 판을 확인하고 캡처한다. 점판이 화면의 주인공인지와 최근 7개와의 구도·색·재질 차이를 캡처로 재검토한다.
