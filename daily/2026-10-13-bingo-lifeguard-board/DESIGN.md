# 빙고 · 해변 구조대 전광판 — 디자인 계획

## 실제 화면 비교

2026-10-13에 최근 게임 7개 경로를 `python3 -m http.server`와 headless Chrome으로 실행해 desktop 캡처를 만들고 비교했다. 실제 `index.html`이 있는 6개(달 착륙선, 하노이 탑, 라이트 아웃, 리버시, 카쿠로, 핀볼)를 확인했다. 최근 화면은 세로형 포스터·장부, 중앙 직사각 격자, 짙은 테두리와 보조 제어부가 자주 보이며, 핀볼은 어두운 포스터, 카쿠로는 종이 장부, 리버시는 천 질감, 라이트 아웃은 유리 질감을 쓴다.

## 방향

**밝은 해변 구조대의 기계식 호출 전광판.** 종이/카드 패널이 아닌, 아이보리 선체에 고정한 큼직한 5×5 번호판을 화면의 80% 가까이 차지하게 둔다. 뽑힌 번호는 왼쪽의 빨간 구명부표 안에서 크게 표시하고, 플레이어는 번호판의 칸을 눌러 줄을 완성한다.

## 실질적 차별화

1. **구도:** 좁은 보조 사이드바 대신, 왼쪽 원형 호출기와 오른쪽 거대한 정사각 번호판을 대각선으로 맞물리게 한다. 게임판이 화면의 주인공이다.
2. **타이포:** 둥근 한국어 고딕 제목과 기계식 숫자용 `Bowlby One SC`를 조합하고, 좁은 모노/명조 중심의 최근 화면과 구별한다.
3. **재질·색:** 어두운 배경/금색을 피하고, 햇빛 아이보리·구조대 빨강·해수 파랑·코르크 점선의 밝은 에나멜 보드 질감을 사용한다.
4. **움직임:** 호출 숫자가 원형 다이얼에서 짧게 회전하며 나타나고, 일치 칸은 구조대 깃발처럼 좌우로 흔들린 뒤 빨간 링으로 고정된다. `prefers-reduced-motion`에서는 정지한다.

## 검증 계획

desktop 1440px와 mobile 390px에서 실제 브라우저로 새 번호 호출, 칸 표시, 빙고 완성, 다시 시작 및 키보드 조작을 확인한다. 새 캡처를 최근 화면과 다시 비교해 카드형 반복·가독성·가로 넘침이 없음을 확인한다.
