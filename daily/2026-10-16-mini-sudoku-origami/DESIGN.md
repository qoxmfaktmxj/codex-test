# 미니 스도쿠 · 종이접기 도감 — 디자인 기록

## 실제 비교
2026-10-16에 로컬 서버와 Chrome headless로 최근 7개(리버시 보자기, 카쿠로 장부, 핀볼 포스터, 빙고 전광판, 필로스 온실, 나인 맨스 모리스 풍향계, 수라카르타 해도)를 1440px 화면에서 캡처해 비교했다. 최근 화면은 넓은 배경 위의 테마 보드, 상단 안내와 보조 정보가 병치되는 구성이 많고, 보자기·장부·포스터·해도처럼 장면성 재질이 강했다.

## 콘셉트
밝은 접이식 종이 한 장을 펼친 듯한 **종이접기 도감**. 4×4 스도쿠 판을 화면의 가장 큰 오브제로 두고, 접힌 삼각 모서리와 미세한 종이 줄무늬가 퍼즐의 작은 칸을 감싼다.

## 차별화
- **구도:** 카드/대시보드 대신 비대칭으로 기울어진 단일 종이판과 바깥 여백을 사용한다.
- **타이포:** 매우 큰 압축 제목과 작고 수직 리듬의 설명을 섞고, 숫자는 판에서만 대형으로 쓴다.
- **재질:** 어두운 바탕·금색 대신 크림 종이, 코발트 잉크, 주홍 교정 표시, 접힌 삼각 모서리로 구성한다.
- **움직임:** 선택·호버 시 종이 칸의 색만 180ms로 바뀌어 판의 상태를 즉시 드러낸다.

## 검증 계획
desktop 1440px 및 mobile 375px에서 실제 클릭으로 숫자 입력, 중복 경고, 완성, 초기화를 확인하고 각각 실제 Chrome 캡처를 저장한다. 최근 화면과 유사하지 않도록 일반 패널과 금색/어두운 바탕을 사용하지 않는다.
