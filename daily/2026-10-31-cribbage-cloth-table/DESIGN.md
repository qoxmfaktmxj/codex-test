# 크리비지 · 붉은 천 테이블 — 디자인 계획

## 실제 비교

2026-10-31에 Chrome headless로 최근 7개(10/24~10/30)를 1280×900 화면에서 직접 캡처해 비교했다. 최근작은 횡단보도·볼링 레인·별 마당·여행 포스터·체육관 코트·원형 관측판·공책 격자로, 모두 밝은 바탕의 넓은 단일 게임판과 큰 제목/보조 설명을 사용한다. 어두운 배경과 금색 강조, 범용 패널 레이아웃은 사용하지 않았다.

## 방향

작은 클럽의 **붉은 펠트 크리비지 테이블**. 손패에서 합계 15가 되는 두 장을 골라 점수를 올리는 미니 크리비지로 만든다. 중앙 카드 테이블과 구불구불한 점수 트랙이 페이지 대부분을 차지하며 정보는 얇은 라벨로만 둔다.

## 실질적 차별점

1. **구도**: 최근의 평면 코트/격자 대신 중앙 타원 테이블, 부채꼴 손패, 둘레의 점수 핀 트랙을 사용한다.
2. **타이포**: 초대형 포스터 제목 대신 좁고 자간이 넓은 클럽 장부 라벨과 카드 숫자의 극단적으로 큰 대비를 쓴다.
3. **재질**: 종이·잔디·콘크리트가 아닌 붉은 펠트, 상아색 카드, 주황색 나무 핀으로 구성한다.
4. **움직임**: 선택 카드의 안정된 들어올림, 15점 성공 시 핀이 트랙을 이동하는 짧은 애니메이션을 적용한다.

## 검증 계획

Desktop 1280×900, mobile 390×844에서 실제 클릭으로 15 조합·완료·새 판 시작과 탭 조작을 확인하고 Chrome 캡처를 저장한다.
