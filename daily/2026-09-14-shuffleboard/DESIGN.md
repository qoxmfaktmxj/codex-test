## 결정한 콘셉트 (구현 전)
밝은 수영장 같은 **청록색 스포츠 코트**. 테이블 셔플보드의 거리 조절을 다섯 번 연습한다. 퍽은 매번 치워 충돌 없는 1인 연습 모드임을 명시한다.
1. 구도: 사이드바/카드 없이 화면을 가로지르는 긴 경기장. 상단은 좌측 대형 제목과 우측 큰 총점, 하단은 수평 조작 띠. 모바일에서도 실제 경기장을 축소하되 조작은 충분히 크게 배치한다.
2. 타이포: 명조나 중앙 정렬 제목 대신 굵고 기울인 한글 고딕, 큰 스포츠 등번호 같은 숫자. 로컬 Noto Sans CJK KR 사용, 외부 폰트 요청 없음.
3. 재질: 목재·종이·금속 음영 없이 시안/흰색의 평평한 코트, 짙은 남색 인쇄선과 주홍색 퍽. 금색과 어두운 배경 없음.
4. 움직임: 차례별 말 선택이나 충돌/바운스 대신 마찰로 천천히 멈추는 수평 활주와 짧은 궤적. 동작 줄이기에서는 궤적을 숨긴다.

스킬 검색의 범용 Hero/Features/CTA, 보라색 추천은 채택하지 않았다. 정적 HTML/CSS/JS와 Node 내장 테스트 패턴만 재사용하며 기존 UI 구조/CSS를 복사하지 않는다.

## 검증 계획
테스트 실패 → 마찰/점수/종료/불변성 로직 구현 → 전체 daily 테스트 → 별도 리뷰어 및 중요 수정. Chrome desktop/mobile에서 실제 입력으로 점수, 다섯 번 종료, 진행 중 리셋, 키보드/터치, 가로 넘침 확인. 실제 캡처를 저장하고 위 7장과 비교한다.
